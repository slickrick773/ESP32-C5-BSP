ESP32-C5 board doctor

For a Waveshare ESP32-C5-Touch-LCD board with a dark screen that seems dead. A dark C5 is very rarely broken: usually the chip still answers over USB and only what is stored on it is wrong. This page asks the chip, says what is wrong in plain words, and can put a known-good test image on it. Nothing to install. Use desktop Chrome or Edge.

1. Connect and check

Plug the board into the computer with a USB cable that carries data. Checking changes nothing on the board.

Ready.












2. Cure


The cure writes this project's board check: a small test program that tries every part of the board and shows a PASS/FAIL table on the screen.



The chip cannot tell the doctor which board it is soldered to. The wrong choice leaves the screen dark; nothing is harmed, and the right choice fixes it.


The cure replaces the firmware on the board.





Before writing, the first 64 KB of the board (bootloader, partition table, start-up choice) is saved to your downloads folder. After writing, every piece is read back and compared.









If the board flickers in and out of the list


A board that shows in the browser's list for a moment and then vanishes, again and again, is restarting over and over. That is the usual "bricked" C5, and it is curable.


    

  1. Press Connect and check and click the board the moment it shows in the list. One click is enough: the browser remembers it.
    2. 

  2. If you missed it, close the list and press Connect and check again. Once the board has been clicked one time, the page waits for it and catches it by itself, even with the list empty.
    3. 








If the chip does not answer


    

  1. Try another USB cable, and a port on the computer itself, not a hub. Many cables carry power only.
    2. 

  2. Close anything else that is using the board's serial port.
    3. 

  3. Put the board in download mode by hand: hold BOOT, tap RST, release BOOT. Then connect again.
    4. 



If the chip never answers in download mode, no software can fix it.
